# Fenbi-reformator

**把粉笔的试卷，调成你想要的样子，然后一键导出 PDF。**

打开预览后，右边有一栏设置。你改任何一个——字号、行距、边距、图片大小——**预览当场变**。满意了就导出，不满意就继续调。

不用反复生成，不用来回切页面，不用等。

## 为什么是「实时」

调一份试卷的麻烦从来不是「生成一次」，而是「调成想要的样子」。

字号大一点还是小一点？题目紧凑一点还是松一点？哪张图放大、哪张缩小？这些问题你**看到效果才知道**。别的工具要你改一次、等一次、看一次、再改一次。Fenbi-reformator 不用——**你改，它当场变**。

调到舒服为止，然后打印。

## 能做什么

- **实时预览**——所有设置改完立即生效，所见即所得
- **一键提取**——打开粉笔做题页点一下，自动抓题目
- **图片单独调**——点任意图片，直接改它的大小，当场看效果
- **三种排版模式**——平衡 / 精细 / 整题，按你习惯选
- **自动保存**——调好的设置下次打开还在
- **配置分享**——一个文件带走所有设置，换电脑、分享朋友都方便
- **封面和注意事项页**——带装订线、粉笔 logo、重要提示，一页不少
- **不上传任何数据**——全程在你电脑里跑，图片、配置、字体都不出本地

## 装它

1. 下载本仓库
2. Chrome / Edge 地址栏输 `chrome://extensions/`（Edge 是 `edge://extensions/`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选本仓库文件夹
5. 装好了

## 用它

1. 打开任意一个粉笔做题页
2. 页面右上角有个悬浮面板，点「重新排版本试卷」
3. 新页面打开预览，右边是设置栏
4. **调到你满意为止**，每一步都能当场看到
5. 点右边的「导出 PDF」，打印目标选「另存为 PDF」，完事

## 三种排版模式

看你的偏好选：

**平衡模式**——题干按段落分，选项按行分，材料整体一块。**块放不下就整块跳下页**，段落绝不跨页。

**精细模式**（推荐）——比平衡更细，块放不下时允许一行一行塞满页面，**尽量不留空白**。

**整题模式**——整道题必须在同一页出现，一题都不会被切开。

切换也是实时的——你在侧栏选一下，预览立刻按新规则重排。

## 图片随便调

预览页点任意一张图，右边就会显示这张图的设置，改「最大高度」，**图片当场变**。

也可以整类一起调——行内图、独立图、材料图，各自的默认大小都在偏好设置里。

## 关于你的数据

所有操作都在你电脑上完成。扩展**不联网**、**不上传**、**不读你的浏览记录**。

排版设置存在浏览器本地，你上传的字体存在浏览器本地。卸载扩展就全删了。
